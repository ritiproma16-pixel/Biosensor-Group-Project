# Saliva-Based Wearable Biosensor for Continuous Cardiac Biomarker Monitoring

**Document Type:** Research Proposal

## Abstract
Heart failure patients face high post-discharge risk. Continuous monitoring reduces readmissions, but current methods are invasive. This proposal presents a mouthguard-based biosensor for detecting troponin and BNP/NT-proBNP in saliva. The device uses an aptamer-functionalized MXene-hydrogel electrode with antifouling and pre-filtration layers. It addresses key commercialization barriers: ultra-low biomarker concentrations, sample variability, biofouling, and lack of clinical validation.

## Problem
- Post-discharge vulnerability phase: up to 50% mortality within one year.
- CardioMEMS proved continuous monitoring works but requires implantation.
- Biomarker trends are more informative than single readings.

## Proposed Solution
| Layer | Function |
|-------|----------|
| Mouthguard | Custom-fit, removable |
| Sensor | Aptamer + MXene-hydrogel electrode |
| Pre-filter | Hydrogel membrane blocks debris |
| Antifouling | Cellulose-acetate coating |
| Signal | Electrochemical aptamer-based sensing |
| Electronics | Bluetooth to phone app |
| Data | Deep learning noise separation |

## How It Addresses Barriers
- **Low concentration:** MXene amplifies weak signals.
- **No saliva-blood correlation:** Built-in calibration model.
- **Messy matrix:** Hydrogel pre-filter.
- **Biofouling:** Antifouling coating.
- **No clinical validation:** Positioned as feasibility step.
- **Wear compliance:** Wear during sleep/rest only.

## Unique Contribution
First to combine MXene-hydrogel with aptamer recognition for cardiac biomarkers. Targets sensitivity and sensor stability. More specific than optical methods; needle- and skin-contact-free.

## Conclusion
A promising non-invasive approach for continuous cardiac monitoring. Future work: prototype development, correlation studies, pilot trials.
